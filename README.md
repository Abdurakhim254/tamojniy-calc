# Таможенный калькулятор (NestJS + React)

Веб-версия по функциям, описанным на странице goldsoft.uz/Program/Info/customs_calculator
(сам интерфейс оригинала — настольная программа для Windows — недоступен для просмотра, поэтому экраны спроектированы заново):
поиск кода ТН ВЭД по описанию, дерево кодов, ставки, список документов, расчёт платежей по партии
из нескольких кодов, режимы импорт / экспорт / временный ввоз, выгрузка в Excel.

**Стек:** backend — NestJS 10 + TypeORM + PostgreSQL (драйвер pg); frontend — React 18 + Vite + TypeScript.

## Запуск (нужен Node.js 18+ и PostgreSQL 14+)

**0. PostgreSQL.** Любой из вариантов:
- Docker: `docker compose up -d` в корне проекта (поднимет PostgreSQL 16 с пользователем/паролем `postgres`);
- или установите PostgreSQL для Windows (https://www.postgresql.org/download/windows/) и запомните пароль пользователя `postgres`.

Параметры подключения по умолчанию: `localhost:5432`, пользователь `postgres`, пароль `postgres`, база `customs`.
Другие значения — в `backend/.env` (скопируйте `backend/.env.example` в `backend/.env`). Базу `customs` backend создаёт сам,
таблицы — тоже.

```bash
# 1. Backend (порт 3000). При первом старте создаёт БД и таблицы и загружает 13 138 кодов из data/codes.xlsx
cd backend
npm install
npm run start:dev          # разработка
# или: npm run build && npm start

# 2. Frontend (порт 5173, проксирует /api на :3000)
cd ../frontend
npm install
npm run dev
```

Продакшен одним процессом: `cd frontend && npm run build`, затем `cd ../backend && npm run build && npm start` —
backend сам отдаёт `frontend/dist` на http://localhost:3000.

Переменные окружения backend: `PORT`, `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` (или одной строкой `DATABASE_URL`), `DB_SSL=true` (облачные БД),
`DB_SYNC=false` (в продакшене отключает автоматическое изменение схемы; тогда схему ведите миграциями), `ADMIN_TOKEN`
(если задан — загрузка данных и смена настроек требуют этот токен; введите его на вкладке «Данные и настройки»).

## Языки интерфейса: русский, English, O'zbekcha

Переключатель RU / EN / UZ в шапке; выбор запоминается в браузере. Что переведено:
- весь интерфейс — `frontend/src/locales.ts` (русский — эталон; TypeScript не даст собрать проект, если в `en` или `uz` не хватает ключа);
- предупреждения, примечания и ошибки сервера, шапки Excel-файла — `backend/src/common/msgs.ts` (язык передаётся в запросе расчёта);
- названия 57 стран — `frontend/src/countries.ts`, единицы измерения (коды ОКЕИ: 796 = шт и др.) — `frontend/src/units.ts`;
- названия льгот УП-145 — в таблице `preference` (поля `name`, `nameEn`, `nameUz`).

**Не переводится:** названия товаров в классификаторе ТН ВЭД — они только на русском (так в исходном файле).
Чтобы добавить язык: допишите словарь в `locales.ts`, `countries.ts`, `units.ts` и `msgs.ts`.

## Интерфейс

Вкладки «1. Найти код» → «2. Рассчитать платежи» → «Данные и настройки». Расчёт идёт «вживую» — результат пересчитывается
при любом изменении полей. Под результатом у каждого товара раскрывается «Как рассчитано»: формулы с подставленными числами.
У полей есть подсказки «?». На телефоне итог закреплён внизу экрана.

## ВАЖНО: чего в проекте нет и что нужно проверить

1. **Ставки платежей.** В присланных файлах их нет. При первом старте загружаются 5 **ДЕМО-ставок**
   (в интерфейсе помечены предупреждением) — замените их импортом: вкладка «Данные и настройки» →
   «Ставки платежей» (шаблон файла скачивается там же), отметьте «Заменить все существующие записи».
   Код в таблице ставок может быть 2–10 цифр: применяется самый точный префикс.
2. **Документы** (сертификаты, лицензии) и **перечни товаров для Туркменистана и Сингапура** — не загружены
   (в проекте есть таблицы `document_req` и `country_goods`; импорт документов готов).
3. **Единицы измерения:** в справочнике они хранятся числовыми кодами. Расшифрованы только самые частые (796, 055, 113, 112, 715, 163, 006, 798, 797, 831, 162, 114); остальные показываются как «№код». У кодов без единицы (7 934 из 13 138) количество указывать нужно только для ставок «за единицу».
4. **Параметры, которые надо сверить с законодательством** (вынесены в настройки, не зашиты в код):
   НДС 12 %, таможенный сбор 0,2 %, дата 01.01.2027 и множитель для стран вне списков,
   3 % в месяц для временного ввоза. Шкала доп. пошлины (+5/10/15/20 п.п. по ст. 3001 ТК РУз) и правило
   «нет сертификата → ×1 + доп. пошлина» взяты из `duty_calc_variants.html` и **не проверены по первоисточнику**
   (`additionalPoints` в `backend/src/calc/calc.service.ts`).
5. **Льготы УП-145** (нулевая пошлина на 22 позиции) загружены с датами из самого документа — с 01.05.2022 по 01.01.2023.
   Чтобы они действовали позже, измените `validTo` в таблице `preference` (или добавьте запись по УП-269, которого нет среди файлов).
6. **Курсы ЦБ** берутся с `https://cbu.uz/ru/arkhiv-kursov-valyut/json/` (в среде разработки проверить не удалось —
   нет доступа в сеть). Если сервис недоступен, курс вводится вручную в форме расчёта.
7. Комбинированные ставки (% и фикс за единицу): берётся **большее** из двух. Это допущение — проверьте по тарифу.

## Логика расчёта (backend/src/calc/calc.service.ts)

```
Тамож. стоимость = (цена + фрахт + страховка) × курс
Режим страны     = ЗСТ, если все три страны (происхождения, отправления, торгующая) в прил. №2;
                   РНБ, если все три в прил. №1; иначе «вне списков»
Нет сертификата  → ставка ×1 + доп. пошлина
ЗСТ              → пошлина ×0
РНБ              → ×1
Вне списков      → до benefitUntil: ×1; после: ×1 + доп. пошлина
Льгота (УП-145)  → пошлина по льготной ставке на период действия (при наличии сертификата)
Пошлина          = стоимость × ставка %   (или фикс × кол-во × курс; при двух — большее)
Акциз            = (стоимость + пошлина) × % (или фикс × кол-во)
НДС              = (стоимость + пошлина + акциз) × НДС %
Сбор             = стоимость × 0,2 %  (потолок — в настройках)
Итого            = пошлина + акциз + НДС + сбор + утильсбор
```

Режим «Экспорт» считает только сбор. «Временный ввоз» умножает пошлину, акциз и НДС на (месяцы × % в месяц).
Не реализовано: расчёт по 4-му методу и по реестру ГТД (есть в оригинале).
